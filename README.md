# Практическая работа №8
## Интернет-магазин на ASP.NET Core MVC

Данный проект представляет собой полноценное веб-приложение для интернет-магазина, разработанное на платформе **ASP.NET Core 8.0** с использованием архитектурного шаблона **MVC (Model-View-Controller)** и ORM **Entity Framework Core**.

---

## 🚀 Основной стек технологий
* **Платформа:** .NET 8.0 (ASP.NET Core MVC)
* **База данных:** MS SQL Server
* **ORM:** Entity Framework Core 8.0 (SQL Server provider)
* **Аутентификация:** Cookie-based Authentication
* **Безопасность (хеширование паролей):** BCrypt.Net-Next
* **Фронтенд:** Razor Views (CSHTML), HTML5, CSS3, Bootstrap

---

## ⚙️ Функциональные возможности

### Клиентская часть (Публичный интерфейс)
* **Каталог товаров:** Просмотр списка товаров с изображениями и ценами.
* **Корзина:** Добавление товаров в корзину, управление количеством, расчет итоговой стоимости.
* **Оформление заказа:** Создание заказа на основе товаров из корзины.
* **Авторизация и Регистрация:** Создание учетной записи пользователя, вход и выход из системы.

### Административная панель (`Areas/Admin`)
Доступна пользователям с ролью `Admin` и позволяет выполнять CRUD-операции (создание, чтение, обновление, удаление):
* **Категории:** Управление каталогом категорий товаров.
* **Товары:** Добавление и редактирование товаров (включая ссылки на изображения, цены, категории).
* **Пользователи и Роли:** Управление зарегистрированными пользователями и распределение ролей (`Admin` / `User`).
* **Заказы:** Просмотр и управление заказами и их позициями.
* **Корзины:** Просмотр активных корзин и их содержимого.

---

## 🗄️ Структура базы данных (Таблицы)
В проекте реализованы следующие сущности:
1. `Products` (Товары) — наименование, описание, цена, ссылка на изображение, связь с категорией.
2. `Categories` (Категории) — группировка товаров.
3. `Users` (Пользователи) — логин, хеш пароля, связь с ролью.
4. `Roles` (Роли) — разграничение прав доступа (`Admin`, `User`).
5. `Carts` и `CartItems` (Корзины и элементы корзины) — сессионное и постоянное хранение выбранных товаров.
6. `Orders` и `OrderItem` (Заказы и позиции заказов) — фиксация покупок.

## 🛠️ Запуск проекта

### 1. Предварительные требования
* Установленный **.NET 8.0 SDK**
* СУБД **MS SQL Server** (LocalDB или Express)

### 2. Настройка подключения к БД
Откройте файл `appsettings.json` и настройте строку подключения `DefaultConnection` под ваш экземпляр MS SQL Server:

```json
"ConnectionStrings": {
  "DefaultConnection": "Server=ВАШ_СЕРВЕР; Database=ShopDB; Integrated Security=True; TrustServerCertificate=True"
}
```

### 3. Автоматическое развертывание и автозаполнение
При первом запуске приложение автоматически:
1. Выполнит необходимые SQL-команды для инициализации/обновления структуры таблиц (если они отсутствуют).
2. Создаст базовые роли `User` и `Admin` (если они отсутствуют).
3. Создаст учетную запись администратора по умолчанию.

### 4. Вход для администратора
* **Логин:** `admin`
* **Пароль:** `admin123`

### 5. Запуск через консоль
Выполните команду в корневой папке проекта:
```bash
dotnet run --project pr3withDB
```
После запуска проект будет доступен по адресу `https://localhost:7198` (или `http://localhost:5246` в зависимости от настроек вашего `launchSettings.json`).
